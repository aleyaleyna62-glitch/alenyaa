Ben Aleyna Günay, 17 yaşında 11. sınıf bilişim öğrencisiyim. Bu site okul ödevim kapsamında hazırlandı ve burada geliştirdiğim projeleri, kullandığım teknolojileri ve yaptığım çalışmaların detaylarını bulabilirsiniz.

Eğitim ve Deneyimler

  • 11. sınıf bilişim öğrencisi olarak temel programlama ve web tasarım bilgisine sahibim.
  • Python ile otomasyon, basit oyun ve hesap makinesi projeleri geliştirdim.
  • HTML ve JavaScript kullanarak interaktif web sayfaları hazırladım.
  • Arduino ve elektronik devreler ile mini projeler ürettim.
  • Problem çözme ve algoritma geliştirme konularında deneyim kazandım.

Projelerimden Örnekler

  • HTML Web Sitesi: Bu site okul ödevi olarak hazırlandı ve tüm sayfalar HTML ile tasarlandı.
  • Python Hesap Makinesi: Basit toplama, çıkarma, çarpma ve bölme işlemleri yapıyor.
  • JavaScript Mini Oyun: Kullanıcı interaktif bir şekilde skor toplayabiliyor.
  • Arduino LED Devresi: LED ışıkları yakıp söndürerek temel elektronik bilgilerini uyguladım.
